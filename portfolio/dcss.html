DC Switching Station (DCSS)

Switchyard controller for IED communication and modular HVDC grid expansion points.

Description

DCSS is the planned switchyard controller providing communication between IEDs and a modular connection point for expandable multi-terminal HVDC grids — complementing PACS (bay/converter C&P) and DCGC (grid control applications).

Status & upgrade plans

  • Work to start in 2027
  • Funding through EXPAND-HVDC (InterOPERA continuation), coordinated by Aleksandra Lekić
  • Intended to be patented
