# Control of HVDC/AC Power Systems

Team website for the Control of HVDC/AC Power Systems group (IEPG / ESE / TU Delft), published via GitHub Pages.

## Preview locally

Open `index.html` in a browser, or from the repo root:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080/

## Rebuild pages

Content is assembled by:

```bash
python scripts/build_site.py
```

## GitHub Pages

1. Repo Settings → Pages → Source: **Deploy from a branch**
2. Branch: `main` · folder: `/ (root)`
3. Site URL will be similar to:
   `https://control-protection-grids-tudelft.github.io/Control-of-HVDC-AC-Power-Systems/`

A `.nojekyll` file is included so asset paths work without Jekyll processing.
