Project description
Project motivation and problem statement
The increasing penetration of converter interfaced renewable energy resources, HVDC transmission systems, battery energy storage systems, and power electronic loads is fundamentally changing the dynamic behaviour of modern power systems. Unlike conventional power systems dominated by synchronous generators, modern converter dominated power systems exhibit strong interactions between AC and DC networks, multiple time scales, and tightly coupled control loops. These characteristics make existing analysis tools insufficient for comprehensive stability assessment. Current software platforms typically focus on only one type of analysis, such as steady state power flow, electromagnetic transient simulation, or small signal analysis, requiring extensive manual model conversion and preventing a unified analysis workflow. This project aims to develop HARMONY, a unified symbolic and numerical framework that integrates power system modelling, optimal power flow, dynamic modelling, and impedance based stability assessment within a single software environment, enabling consistent and automated analysis of converter dominated AC/DC power systems.
How can a unified modelling framework be developed to seamlessly bridge steady-state analysis, dynamic modelling, and frequency-domain stability assessment for converter-dominated hybrid AC/DC power systems?
How can symbolic and numerical computation be integrated to automatically derive component models, assemble network equations, and efficiently perform scalable harmonic stability assessment?

Challenges
Developing such a unified framework presents several challenges. First, different analysis methods require fundamentally different mathematical representations, ranging from nonlinear algebraic equations for power flow to state space models and frequency dependent impedance models for stability assessment. Maintaining consistency among these representations while avoiding repeated model development is highly challenging. Second, converter dominated power systems involve heterogeneous components, including modular multilevel converters (MMCs), VSC HVDC transmission systems, renewable energy resources, and battery energy storage systems, each with different control architectures and operating modes that need to be represented within a common modelling framework. Finally, large AC/DC systems introduce significant computational complexity because of large symbolic models, sparse network assembly, and repeated frequency domain calculations, requiring efficient numerical algorithms and a scalable software architecture.
Proposed approach
The proposed research will develop the HARMONY framework based on a modular and hierarchical software architecture. A unified graph based network representation will be established to describe AC/DC systems and component interconnections. Symbolic modelling techniques will automatically generate state space equations, linearized models, and terminal admittance matrices from reusable component descriptions. These symbolic models will then be integrated with numerical solvers for optimal power flow, operating point computation, and impedance based harmonic stability assessment. By combining symbolic computation, sparse numerical algorithms, and automated analysis workflows, HARMONY will provide a unified software platform that substantially reduces modelling effort, maintains consistency across different analysis methods, and enables efficient stability assessment of future converter dominated power systems.
